# Quan hệ giữa các repository

- [`rightly-beta/dev`](https://github.com/neornotl/rightly-beta/tree/dev) là nơi phát triển và kiểm thử liên tục.
- [`rightly-beta/release`](https://github.com/neornotl/rightly-beta/tree/release) là nhánh nguồn để chuẩn bị phát hành.
- [`rightly/release`](https://github.com/neornotl/rightly/tree/release) là repo release công khai, đồng bộ từ nhánh release nguồn.

Địa chỉ web giữ nguyên: [https://intel-demo-topaz.vercel.app/](https://intel-demo-topaz.vercel.app/). Vercel hiện theo dõi `rightly-beta/dev` nhưng URL người dùng không đổi.
